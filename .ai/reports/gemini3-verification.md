## সমস্যা ৩ — সংখ্যা মেলে না

স্ক্রিপ্ট দিয়ে ৫৫২টি blade ফাইল স্ক্যান করে পাওয়া বাস্তব সংখ্যা:

| | Gemini | বাস্তব |
|---|---|---|
| inline `<script>` আছে | ১৭০ ফাইল (প্রম্পট থেকে ধরে নেওয়া) | **১৬২ ফাইল, ২৪৬ block** |
| `$(document).ready` / `$(function` | A = ১০২ ফাইল | **৭২ ফাইল, ১০৫ বার** |
| `$(document).on(...)` (delegation) | B = ২৪ ফাইল | **৬৯ ফাইল, ১৮৮ বার** |
| মোট script block | ২০১ (৫ শ্রেণির যোগফল) | **২৪৬** |

B শ্রেণি বিশেষভাবে গুরুত্বপূর্ণ — event delegation একাধিকবার bind হলে
একটি ক্লিকে দুইবার ajax যাবে। ২৪ নয়, ৬৯টি ফাইলে এটি আছে।
